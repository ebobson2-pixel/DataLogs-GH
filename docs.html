Agent API

Connect your website to DataLogs GH

Generate an API key in your dashboard, then buy data for customers from your own site. The live base URL is https://datalogsgh.shop/api/v1.

1. Get your API key

  1. Sign in to your agent dashboard.
  2. Open API keys in the sidebar.
  3. Name the key (for example “My website”) and tap Generate API key.
  4. Copy the secret immediately. It starts with dlg_live_ and is shown only once.

You can keep up to 5 active keys. Revoke a key if it leaks. After you revoke it, that website must use a new key.

2. Authentication

Every request except GET /health needs your key.

Base URL

https://datalogsgh.shop/api/v1

Header (pick one)

Authorization: Bearer dlg_live_your_key_here
X-API-Key: dlg_live_your_key_here

Send JSON with Content-Type: application/json on POST requests. Your website can call this API from any domain.

3. List packages

Use this to show bundles on your site. Prices are your wholesale rate, including any custom price DataLogs GH set for you.

GET /packages

Optional filter: GET /packages?network=mtn · also airteltigo or telecel.

curl "https://datalogsgh.shop/api/v1/packages" \
  -H "Authorization: Bearer dlg_live_your_key_here"

Example response

{
  "ok": true,
  "data": {
    "packages": [
      {
        "id": "uuid-of-package",
        "network": "mtn",
        "gb": 1,
        "price": 4.5,
        "currency": "GHS",
        "validity": "Non expiry"
      }
    ]
  }
}

4. Place an order

POST /orders buys a bundle for a Ghana number. Use either a package id from step 3, or network + GB.

The number must match the network (MTN prefixes such as 024, AirtelTigo 027, Telecel 020).

curl -X POST "https://datalogsgh.shop/api/v1/orders" \
  -H "Authorization: Bearer dlg_live_your_key_here" \
  -H "Content-Type: application/json" \
  -d "{\"package_id\":\"uuid-of-package\",\"recipient\":\"0241234567\"}"

Same order using network and size:

{
  "network": "mtn",
  "gb": 1,
  "recipient": "0241234567"
}

Success looks like this. status is only processing or completed.

{
  "ok": true,
  "data": {
    "order": {
      "order_code": "DL-A1B2C3D4",
      "network": "mtn",
      "gb": 1,
      "recipient": "024 123 4567",
      "amount": 4.5,
      "currency": "GHS",
      "status": "processing",
      "created_at": "2026-08-14T12:00:00.000Z"
    }
  }
}

Save order_code so you can look the order up later. Delivery starts automatically after the order is created.

5. Check an order

GET /orders/DL-A1B2C3D4

curl "https://datalogsgh.shop/api/v1/orders/DL-A1B2C3D4" \
  -H "Authorization: Bearer dlg_live_your_key_here"

List your recent API / wholesale orders: GET /orders?limit=20 (max 50).

6. Wallet

GET /wallet returns your commission wallet balance in Ghana cedis.

curl "https://datalogsgh.shop/api/v1/wallet" \
  -H "Authorization: Bearer dlg_live_your_key_here"

Errors & status

Failed responses always include ok: false and a short message you can show to yourself, not always to the customer.

HTTPerrorWhat to do
200 / 201—Request worked.
400bad_requestFix the number, network, or package.
401unauthorizedCheck the key. Generate a new one if it was revoked.
404not_foundWrong URL or unknown order code.

Order status for your customers

  • processing — payment recorded, bundle is being sent.
  • completed — delivery is done.

Do not show any other status on your website.

Health check (no key): GET https://datalogsgh.shop/api/v1/health

Website examples

Copy one of these into your backend. Never put the API key in browser JavaScript that customers can view. Call DataLogs GH from your server.

JavaScript (Node)

const BASE = "https://datalogsgh.shop/api/v1";
const KEY = process.env.DATALOGS_API_KEY;

async function buyData({ packageId, recipient }) {
  const res = await fetch(`${BASE}/orders`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ package_id: packageId, recipient }),
  });
  return res.json();
}

PHP

$base = "https://datalogsgh.shop/api/v1";
$key = getenv("DATALOGS_API_KEY");

$ch = curl_init("$base/orders");
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => [
    "Authorization: Bearer $key",
    "Content-Type: application/json",
  ],
  CURLOPT_POSTFIELDS => json_encode([
    "network" => "mtn",
    "gb" => 1,
    "recipient" => "0241234567",
  ]),
]);
$response = json_decode(curl_exec($ch), true);

Python

import os, requests

BASE = "https://datalogsgh.shop/api/v1"
KEY = os.environ["DATALOGS_API_KEY"]

r = requests.post(
    f"{BASE}/orders",
    headers={"Authorization": f"Bearer {KEY}"},
    json={"network": "mtn", "gb": 1, "recipient": "0241234567"},
    timeout=30,
)
print(r.json())

Suggested flow on your site

  1. Your server calls GET /packages and displays network, GB, and price.
  2. Customer picks a bundle and enters a Ghana number.
  3. You collect payment on your site first.
  4. Your server calls POST /orders with that package and number.
  5. Show the customer order_code and status processing or completed.
  6. Optionally poll GET /orders/ORDER_CODE every few seconds until it is completed.
