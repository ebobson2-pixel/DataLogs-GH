How it works

Buy data in four clear steps

No app install. No agent hunt. Pick a package, pay once, and follow your order until it lands on the number. Most customers finish in under two minutes.

  1. 1
    Choose network & size

    Open Buy data, pick MTN, AirtelTigo or Telecel, then select the GB you need. Compare sizes and prices before you tap buy.

  2. 2
    Enter the phone number

    Type the Ghana number that should receive the bundle. Double-check the network matches the SIM — MTN data cannot load on a Telecel line, and so on.

  3. 3
    Pay with MoMo or card

    Checkout runs through Paystack. You pay the package price shown — plus the small Paystack fee when you use MoMo or card. Wallet checkout (where available) uses the package price only.

  4. 4
    Track until delivered

    Save your order code from the confirmation screen. Use Track order, the floating tracker, or Track transaction on this page anytime to see status.

FAQ

Common questions

Quick answers before you buy. Still stuck? Open WhatsApp from the green button or track your order with the code from checkout.

Do I need an account to buy data?

No. You can buy as a guest. An account is optional and helps if you reorder often or want to keep purchase history.

How long does delivery take?

Most orders finish within 1–5 minutes after Paystack confirms payment. If it takes longer, use Track order with your order code — status updates as the bundle is processed.

Which payment methods work?

Mobile Money and cards via Paystack. Signed-in customers and agents may also pay from wallet balance where that option is shown at checkout.

What if I pick the wrong network?

The bundle must match the recipient SIM. Always select MTN, AirtelTigo, or Telecel based on the line receiving the data before you pay.

How do I track my order?

Use Track order in the menu, the floating tracker, or Track transaction on this page. Enter the order code from checkout or the recipient phone number.

Can I sell data as an agent?

Yes. Register under Become an agent to open a mini store, set your prices, manage a wallet, and share flyers with customers.
